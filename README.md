\# CodeSage AI



\*\*An AI-powered code analysis tool built with Python and Streamlit.\*\*



\## Overview



CodeSage AI is a developer-focused project designed to analyze source code and provide useful insights through a simple web interface.



\## Features



\* Interactive web interface using Streamlit

\* Code analysis through the `codesage` Python package

\* Automated tests using pytest

\* Modular and maintainable project structure



\## Tech Stack



\* Python

\* Streamlit

\* Pytest



\## Project Structure



```text

CodeSage-AI/

│   └── analyzer.py

├── tests/

│   └── test\_analyzer.py

```



\## Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/mohanmudadla/CodeSage-AI.git

&#x20;  cd CodeSage-AI

&#x20;  ```



2\. Create and activate a virtual environment:



&#x20;  ```bash

&#x20;  python -m venv .venv

&#x20;  ```



&#x20;  Windows PowerShell:



&#x20;  ```powershell

&#x20;  .venv\\Scripts\\Activate.ps1

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Run the application:



&#x20;  ```bash

&#x20;  streamlit run app.py

&#x20;  ```



\## Testing



Run the automated tests using:



```bash

python -m pytest

```
